Open Design 数据库表结构设计文档

数据库概览

数据库引擎：SQLite（通过 better-sqlite3@12.10.0 驱动）

数据库文件：<dataDir>/app.sqlite（dataDir 默认为 <projectRoot>/.od，可通过 OD_DATA_DIR 覆盖）

连接配置：journal_mode = WAL，foreign_keys = ON

迁移方式：幂等 CREATE TABLE IF NOT EXISTS + 基于 PRAGMA table_info 的 ALTER TABLE ADD COLUMN 前向兼容增量

启动入口：apps/daemon/src/server.ts 解析 OD_DATA_DIR 为 RUNTIME_DATA_DIR，由 openDatabase() 打开并执行 migrate(db)。
