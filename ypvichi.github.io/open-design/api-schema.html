接口概览

HTTP 框架：Express（daemon 进程内嵌 HTTP 服务）

路由注册：各模块通过 register*Routes(app, ...) 在 daemon 启动时挂载到 Express app，路由前缀统一为 /api/*

认证：本地 daemon 请求需通过 requireLocalDaemonRequest 中间件校验；部分接口需 API token 或 desktop auth

契约层：共享 DTO 位于 packages/contracts，UI 与 CLI 均通过同一 /api/* 端点访问（AGENTS.md 双轨契约）

入口：apps/daemon/src/server.ts 创建 Express app 并调用各 register*Routes

数据类型分类：用户设计业务数据 = 用户动态创建的设计业务数据（项目、对话、文件、设计系统、品牌、制品、模板、记忆条目、部署、媒体任务、评论、插件快照、自动化/例程配置等），需账号级数据隔离；系统运行数据 = 系统运行所需的其他数据（健康检查、诊断、版本、预览隔离、daemon 状态/关闭、MCP 安装/OAuth、遥测、分析配置、静态资源、连接器发现、应用配置、终端管理等）
